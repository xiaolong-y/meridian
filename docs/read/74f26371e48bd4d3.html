Open Quantum Launches Native Qrisp Integration for High-Level QPU Execution Across IonQ, Rigetti, IQM, and AQT Hardware

Quantum Computing Report Mohamed Abdel-Kareem 1d quantum 426 words 3 min read

Quantum execution platform Open Quantum (developed by Quantum Rings in partnership with qBitTensor Labs) has released a native software integration for Qrisp, an open-source, high-level quantum programming language maintained under the Eclipse Foundation in collaboration with Fraunhofer FOKUS.
Available via Python package managers (pip install "openquantum-sdk[qrisp]"), the plugin allows developers to compile and execute high-level Qrisp programs directly on physical quantum processing units (QPUs) from IonQ, Rigetti Computing, IQM Quantum Computers, and AQT without writing vendor-specific gate-level code or altering algorithm logic.

Traditional quantum development SDKs require engineers to manually wire individual physical qubits, apply discrete logic gates, and explicitly manage uncomputation routines to free up ancillary qubits. In contrast, Qrisp introduces software-engineering abstractions to quantum computing—utilizing typed quantum variables (QuantumVariable), automated qubit allocation, memory management, and built-in quantum arithmetic modules.
The Open Quantum Qrisp plugin interfaces directly with native execution routines (QuantumVariable.get_measurement and QuantumCircuit.run), providing single-string backend switching across both trapped-ion and superconducting architectures. The SDK automatically compiles Qrisp data structures into intermediate Qiskit circuit representations, flattens multi-register variables, validates the circuit against the target QPU’s basis gate set and coupling map, and submits the job via OpenQASM before decoding measurement counts directly back into Qrisp’s native data types.
This integration expands upon Qrisp’s high-level CUDA-Q integration, builds on Qrisp 0.8’s compilation benchmarks for Shor’s algorithm, and supports broader European open-source software goals under the Horizon Europe Q-VERSE consortium. It also complements Qrisp’s recognition at the Quantum Effects Awards 2026, as well as IQM’s contributions to open-source QAOA libraries and Resonance cloud QPU infrastructure.
