Horizon Quantum Integrates Triple Alpha IDE with OQC’s Toshiko Processor for Pulse-Level Control

Quantum Computing Report Mohamed Abdel-Kareem 7h quantum 295 words 2 min read

Quantum software developer Horizon Quantum Computing (NASDAQ: HQ) and superconducting hardware manufacturer Oxford Quantum Circuits (OQC) have completed a pulse-level hardware integration connecting Horizon’s Triple Alpha integrated development environment (IDE) to OQC’s 32-qubit processor, Toshiko. The interface exposes the physical control layer directly within the IDE, allowing users to execute pulse scheduling, qubit characterization, and automated gate calibration alongside standard high-level application code.
Operating superconducting processors requires precise microwave pulse calibration to drive quantum gates and mitigate coherent phase errors. Typically, low-level pulse modulation and physical system characterization are isolated within specialized control-system software, decoupled from application-layer development environments. In this implementation, Triple Alpha connects directly to Toshiko’s control plane via a web API, enabling users to benchmark physical qubit decay parameters—including relaxation time (T1) and phase coherence (T2)—and adjust pulse envelopes for single- and two-qubit operations without switching toolchains.
The integration expands Triple Alpha’s abstraction model, which translates algorithm logic into hardware-specific execution schedules while maintaining access to physical control variables. For OQC, providing programmatic pulse access to Toshiko allows enterprise and academic researchers to deploy custom dynamical decoupling sequences and optimize native gate fidelities directly on its 3D coaxial (“Coaxmon”) architecture.
