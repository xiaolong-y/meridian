Q-SAFE Solutions Unveils EU-27 Carrier-Grade Quantum-Safe Network Platform

Quantum Computing Report Mohamed Abdel-Kareem 10h quantum 377 words 2 min read

German quantum communications company Q-SAFE Solutions GmbH has introduced a carrier-grade secure communications platform engineered within the EU-27. Designed for telecommunications providers, critical infrastructure operators, and government agencies, the platform integrates Quantum Key Distribution (QKD), Post-Quantum Cryptography (PQC), and centralized hybrid key management into a single sovereign system compliant with European EuroQCI procurement requirements.
Operating over existing production fiber-optic infrastructure alongside conventional data traffic, the system eliminates the operational requirement for dedicated dark fiber lines. Keys are generated via hybrid QKD-PQC key agreement mechanisms—combining physics-based QKD entropy with standardized post-quantum key encapsulation mechanisms (KEMs)—and distributed to existing network encryptors and applications via standardized ETSI GS QKD 004 and ETSI GS QKD 014 interfaces, including EU- and NATO-approved cryptographic devices.

| Management & Standards | • Standard ETSI GS QKD 004 / 014 • Unattended carrier-grade monitoring | • Native integration with OSS, NMS, SDN, API • Compatible with EU/NATO-certified encryptors |
The architecture allows operators to initially protect high-priority links—such as inter-datacenter backbones, cross-border connections, and command-and-control links—before expanding across national backbones using trusted node relays. Managed via standard Operations Support Systems (OSS), Network Management Systems (NMS), and Software-Defined Networking (SDN) interfaces, the system is designed for automated, unattended operation by regular network personnel without requiring specialized lab physicists on-site.
As an independent entity founded, integrated, and quality-tested in Germany without third-party foreign state control, Q-SAFE aligns directly with EU technological sovereignty mandates. The company will showcase live functional systems at the European Commission’s QCI Days 2026 conference in Padua, Italy, from September 28 to 30.
