NEC and IBM Japan Demonstrate Hybrid QKD and Post-Quantum Cryptography TLS Proxy Architecture

Quantum Computing Report Mohamed Abdel-Kareem 14h quantum 388 words 2 min read

NEC Corporation and IBM Japan have completed a joint demonstration integrating quantum key distribution (QKD) with post-quantum cryptography (PQC) inside a single Transport Layer Security (TLS) proxy architecture. Executed between July and September 2026, the trial connected NEC’s QKD hardware with a customized deployment of IBM Quantum Safe Proxy (formerly IBM Quantum Safe Remediator) to validate multi-vendor cryptographic interoperability without requiring modifications to existing enterprise applications.

By placing the proxy layer in front of existing communication endpoints, the setup allowed legacy software to adopt dual-layer key exchange while preserving standard network workflows. Rather than treating QKD as a standalone substitute for classical public-key infrastructure, the validation combined both key sources in parallel so session security benefits from both physical key distribution and lattice-based cryptography.
The companies noted that the trial focused specifically on combined key establishment and standardized API interoperability, and did not evaluate QKD as an alternative to certificate-based authentication or as an automatic fallback channel when optical QKD links are unavailable. Looking ahead, NEC and IBM Japan plan to explore commercial deployments for financial institutions, core banking transaction systems, and inter-data-center communications.
