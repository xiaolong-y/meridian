Qilimanjaro Quantum Tech Releases QiliSDK v0.3.0 with GPU-Accelerated Analog Simulation and Python 3.14 Support

Quantum Computing Report Mohamed Abdel-Kareem 7h quantum 296 words 2 min read

Barcelona-based analog quantum computing startup Qilimanjaro Quantum Tech has released version 0.3.0 of its open-source QiliSDK framework and QiliSim C++ backend engine. Built to unify circuit-based digital algorithms, Hamiltonian-driven analog time evolution, and hybrid variational workflows within a single Python API, the software update introduces GPU acceleration for variational annealing and expands classical optimization capabilities.
The v0.3.0 release adds full support for Python 3.14, an upgraded tensor network engine (QTensor), and a dedicated classical solvers module featuring a high-performance simulated annealing algorithm. For analog schedule modeling, the framework now supports time-dependent noise profiles, simplified operator drawing tools, and a unified Expression class that merges symbolic terms and variables. Within the underlying C++ simulator (QiliSim), the team integrated a new stabilizer state simulator for efficient Clifford circuit verification and enabled GPU acceleration to speed up complex variational schedules.

Licensed under Apache-2.0, QiliSDK operates as a backend-agnostic control layer capable of targeting CPU simulators, GPU acceleration clusters, and Qilimanjaro’s cloud-accessible analog quantum processing units (QPUs). The open-source package is available for installation via PyPI and GitHub.
