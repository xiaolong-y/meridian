Infleqtion and Riverlane Execute Strategic MOU to Integrate Neutral-Atom Hardware with Real-Time QEC Decoders

Quantum Computing Report Mohamed Abdel-Kareem 20h quantum 256 words 2 min read

Quantum technology developer Infleqtion (NYSE: INFQ) and quantum error correction (QEC) software specialist Riverlane have executed a Memorandum of Understanding (MOU) to integrate real-time fault-tolerant decoding infrastructure with neutral-atom hardware architectures. Announced in Oxford, the strategic partnership combines Riverlane’s Deltaflow real-time QEC decoding platform and Deltakit diagnostic suite with Infleqtion’s Sqale neutral-atom QPU platform, Superstaq compiler, and quantum low-density parity-check (qLDPC) algorithmic library.
The collaboration focuses on closing the latency gap between physical qubit error detection and real-time syndrome processing, a core requirement for generating logical qubits at scale. While physical neutral-atom arrays utilize optically trapped alkali/alkaline-earth atoms (such as cesium or rubidium) controlled via Rydberg blockade gates, environmental noise and laser pulse fluctuations necessitate sub-millisecond, real-time decoding feedback. By pairing Infleqtion’s qLDPC software—developed to reduce physical-to-logical qubit overheads by 10× to 100×—with Riverlane’s dedicated ASIC/FPGA decoder hardware, the partnership establishes a co-designed stack designed to run dynamic error correction cycles without interrupting execution runtime.
